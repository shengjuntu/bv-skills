# 渲染器参数表

所有渲染器共享的顶层 spec 字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `chapter` | 是 | 01-20，决定 renderer |
| `renderer` | 否 | 显式覆盖路由结果 |
| `out` | 是 | 输出路径前缀（不带扩展名） |
| `formats` | 否 | `["png"]`（默认）/ `["png","svg","pdf"]` |
| `title` | 是 | 图标题，评审会检查 |
| `note` | 建议 | 数据性质说明（示例/真实/模拟） |
| `date_format` | 否 | `"ym"` 强制年月解析，`"decimal"` 强制按数值 |
| `date_columns` | 否 | 需要按时间解析的列名列表 |
| `primary_key` | 否 | 重复检查用的主键列 |
| `bounds` | 否 | `[{"col":"v","min":0,"max":100}]` |
| `font_path` | 否 | CJK 字体路径，缺省走内置探测 |
| `dpi` | 否 | 默认 140 |
| `data` | 是 | `{"path":...}` 或 `{"rows":[...]}` |

## timeseries（02/11）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `x` | 是 | 时间列（`2019.3` 会按年月解析成 2019.1667） |
| `series` | 否 | `[{"name":"规模","y":"v"}]`，缺省取所有数值列 |
| `events` | 否 | `{"col":"事件名","at":"时间列","cat":"类别列"}`，画在下方事件面板 |
| `zero_baseline` | 否 | 默认 `true`；设 `false` 必须给 `baseline_reason` |
| `label_points` | 否 | 默认 `true`，标首末值 |
| `y_label` / `events_title` | 否 | 轴标签 / 事件面板标题 |

## matrix（04/12/14/15/16）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `rows` / `cols` / `value` | 是 | 行名、列名、数值列 |
| `expected` | 否 | `{"行|列":1}`，给了就出"期望 vs 实际"双面板并标红框空洞 |
| `cmap` | 否 | 默认 `YlOrBr` |

## network（07/08/10）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `source` / `target` | 是 | 边两端 |
| `weight` | 否 | 边权重（用于阈值过滤） |
| `threshold` | 建议 | 低于此值的边丢弃；不给会 warn |
| `layout` | 否 | `kamada_kawai`（默认）/ `circular` |

0 度节点不参与布局，单列在右侧并标"（孤立）"。

## geo（05/06）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `routes` | 是 | `[{"name":"A→B","points":[{"lon":..,"lat":..,"t":..}]}]` |
| `origin_label` | 否 | 共起点标签，默认"共起点" |

所有路线首点相同时只画一个星标 + 一个"共起点"，终点用编号，全名进图例框。

## smallmultiples（13）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `facet` / `x` / `y` | 是 | 分面列、横轴、纵轴 |
| `ncol` | 否 | 默认 3 |

缺失点：折线在此断开 + 灰色竖虚线 + 面板内"未采集：…"文字。不补零、不跨点直连。

## scatter（09）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `x` / `y` | 是 | 投影坐标 |
| `cluster` | 否 | 簇列 |
| `outlier_labels` | 否 | `["稀疏"]`，这些簇用灰色并标"（稀疏/异常）" |
| `x_label` / `y_label` | 否 | 轴说明，默认写"示意" |

## volume（18）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `grid` | 否 | 网格边长，默认 64 |
| `peaks` | 否 | `[{"c":[x,y,z],"s":σ,"a":幅度}]`，切片自动过峰值 |
| `cmap` | 否 | 默认 `inferno` |

三片共用一个 `vmax`（全场最大），因此切片间可直接比亮度。

## multimodal（17）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `metrics` | 是 | `[{"name":"流量","value":72}]` |
| `pitch_base` / `pitch_gain` | 否 | 音高 = base + gain × value，默认 220 / 4 |
| `write_wav` | 否 | `true` 则在同目录写 `<out>.wav` |
| `sample_rate` | 否 | 默认 22050 |

## animation（19）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `points` / `frames` / `fps` | 否 | 默认 40 / 12 / 8 |
| `dx` / `dy` | 否 | 位移量，默认 1.4 / 0.6 |

产物：`<out>.gif` 与 `<out>.png`（静态起止帧）。

## wordcloud（03）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `word` / `count` | 是 | 词与频次列 |
| `top` / `max_words` | 否 | 核对面板条数（默认 15）/ 词云词数（默认 120） |
| `font_path` | 否 | CLI 会自动注入已探测到的 CJK 字体 |

右侧固定出 Top-N 原始频次 + 占比条形面板，词云面积不可用于跨语料比较。
